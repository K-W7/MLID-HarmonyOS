## 第二轮（20:00–20:25，v1.3.0）

### 本轮修复

| 问题 | 处理 |
|---|---|
| 隐私页停在半截 | `scroller.scrollEdge(Top)` 每次进入复位 |
| 切浅色后主页仍黑底、11月不可见 | 色温改读**应用主题设置**（不再只看 `context.config`） |
| 主题切换“半新半旧” | 注册 `environment` 回调，主题变化后刷新 `tint`；背景用 `animateTo` 1200ms 过渡 |
| 浅色下状态栏图标看不见 | `ThemeUtil.applyTheme` + 启动页各自同步 `statusBarContentColor` |
| 点图标先闪黑一帧 | `EntryAbility` 按持久化主题预置窗口底色 |
| 切页闪黑 | `Navigation` / `NavDestination` 补当前色温底色 |
| 返回箭头位置不一致 | 记录页 header 左边距 12 → 20，与设置页对齐 |
| 启动页黑底、不跟主题 | 重写为**浅色/深色两套**；`peekThemeMode()` 同步读主题，第一帧即正确 |
| 启动页黑屏闪一下 | 只淡内容不淡背景，底色保持到 `replaceUrl` |
| 启动页字“划过去”很怪 | 改回逐字淡入 + 6vp 上浮，布局不动 |
| 印章“叙”不好看 | 印文改「記」，纯朱砂字、无色块 |
| 情绪胶囊常驻 / 进页自动展开 | `aboutToAppear` 静默收起；仅手指点过输入框才允许焦点展开；失焦且空内容自动收起 |
| 草稿进页就弹键盘 | 草稿只填充不展开；草稿卡仅在岛展开时渲染 |
| 设置页空旷 | 删除「清理缓存」（无实际缓存），改为启动时自动清 `cache_dir` 临时文件 |
| 设置页文档一致性 | 删「每晚提醒/提醒时间」；隐私第 5 条改为不请求通知、第 7 条去掉「提醒」；更新日期改为 2026-11-08 版本 1.3 |

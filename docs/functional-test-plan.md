# 功能测试计划（按 SRS 的 40 条 FR）

状态：⬜ 未测 / 🟢 通过 / 🔴 缺陷 / ⚠️ 与文档有意的偏离（不是 bug）

测试方式：
- **自动**：控件树定位（`uitest dumpLayout`）+ 单击/滑动 + 截图对比 + `hilog`
- **手测**：弹窗、手势、键盘、Picker 这类 `uitest` 不可靠的，由用户点并描述
- 每条都要留证据：截图文件名或 hilog 行

前置：手机前台必须是 `com.k.mlid`（安卓版 `com.mlid.app` 也在机上，界面像，要 `aa force-stop com.mlid.app`）。

# 时叙 MLID

> 会呼吸的情绪日记。安静、完全本地、无社交压力的鸿蒙原生日记应用。

这是「时叙」的 **HarmonyOS 版**源码（此前开源过 Android 版，本仓库是鸿蒙原生重写）。
用 ArkTS + ArkUI 声明式开发，目标 SDK：API 26（HarmonyOS 26.0.0）。

---

## 它是什么

- **完全本地**：不申请任何权限，不含网络代码、无账号、无云同步、无第三方 SDK
- **官方能力优先**：日历交互、拖拽排序、页面转场、图片转场、材质与动效，都走 HarmonyOS 官方 API
- **克制**：没有推送、没有连续打卡、没有社交，写不写都不催你

## 主要功能

| 模块 | 内容 |
|---|---|
| 主页 | 月标题 + 大日期（+ 星期 · 当日记录数）+ 周日开头的 6×7 网格；每格带农历，节气/节日用赤陶色，有记录的日子带暖金点 |
| 回望区 | 昨日回望 / 随机一条 / 往年今日三块卡片堆叠：上叠、可循环翻看、长按拖拽排序、无数据的块自动隐藏 |
| 单日页 | 底部悬浮岛输入（点开才显示情绪胶囊）+ 草稿实时卡 + 保存落笔动画；左滑引用/删除；长文展开收起 |
| 设置 | 外观（跟随系统/浅色/深色）、数据（导出/导入/清空/重置）、关于 |
| 备份 | 普通 ZIP 或加密 `.mlidbackup`（PBKDF2-HMAC-SHA256 + AES-256-GCM） |

## 配色：ABC 三层

- **B 纸墨底座**：浅色 `#F5F0EC` / 深色 `#141311`
- **A 情绪色温**：记了情绪就用主情绪色，没记就按当前时段（晨/午/暮/夜）给一个兜底色温
- **C 光感**：顶部径向光，色温跟着 A 走

## 构建

1. 用 **DevEco Studio** 打开本仓库（推荐与 API 26 对应的版本）
2. `File → Project Structure → Signing Configs` 里配置**你自己的签名**（仓库不含任何签名材料）
3. 执行 `hvigorw assembleHap --mode module -p product=default` 或直接点 Run

命令行构建需要两个环境变量：

```powershell
$env:DEVECO_SDK_HOME = "<你的 DevEco SDK 路径>"
$env:JAVA_HOME = "<DevEco 自带 jbr 路径>"
```

## 签名配置

仓库里**不包含任何签名材料**（证书、私钥、口令都不在版本库里）。`build-profile.json5` 的 `signingConfigs` 是空数组。

要装到真机，你需要自己生成签名：

1. DevEco Studio → `File → Project Structure → Signing Configs`
2. 勾选「Automatically generate signature」（需登录华为账号）
3. 生成后再构建，产物是 `entry-default-signed.hap`

这样每台机器的签名各自独立，仓库保持干净。

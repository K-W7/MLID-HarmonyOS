# 变更提案：根据 SRS/SDD 规格说明书进行深层次修改

## 业务意图

根据《时叙 MLID 鸿蒙原生应用软件需求与系统设计规格说明书》（MLID-SRS-SDD-001）中定义的全部功能需求与非功能需求，对现有应用进行深层次修改、完善与美化，使功能完整度与规格文档对齐。

## 本次变更覆盖的功能模块

### 1. 日历主页回望区（FR-CAL-005～FR-CAL-008）
- **昨日记录**：取代现有的「今日记录」，显示昨天的记录卡片（或空状态）
- **随机一条**：已实现，需验证
- **往年今日**：已实现，需验证
- **可排序**：用户可通过拖拽或设置页面调整三个模块顺序，持久化到 Preferences

### 2. 日历格网视觉完善（FR-CAL-001.7）
- 有记录日期在数字下方显示 2×2vp 圆点（灰色），用于区分主记录与批注
- 未来日期保持只读外观

### 3. 隐私同意流程（FR-APP-003）
- 首次启动显示隐私协议弹窗
- 不同意则退出应用
- 同意后持久化，下次不再弹出

### 4. 设置页完善（FR-SET）
- 深色模式：跟随系统 / 浅色 / 深色 三种，实时切换
- 每晚提醒：授权、设置时间、取消；通知点击跳转当天
- 导出：普通导出 + 加密导出（AES-GCM）
- 导入：支持 `.zip` / `.mlidbackup`，含去重
- 未归档管理：单条/批量归档
- 清空记录：两步确认
- 重置应用：两步确认

### 5. 记录批注（FR-REC-004）
- 记录可含多个批注（annotation）
- 批注有自己的内容、情绪、时间戳
- 单日详情页中批注折叠在主记录卡片内

### 6. UI/UX 美化
- 减弱动画选项
- 大字模式
- 统一视觉 Token 使用（确保无硬编码数值）
- 圆角、阴影、间距符合设计系统

## 不纳入本次变更

- 数据库迁移至 RelationalStore（规模过大，留待下一阶段）
- 多语言/国际化支持
- 无障碍深度优化（仅实现减弱动画/大字等轻量需求）
- 启动页（已有，不修改）
